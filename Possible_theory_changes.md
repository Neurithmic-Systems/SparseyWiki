## Add a mode in which all evidence combination, even within a single bundle, is multiplicative.

# The old way

In the original version, where there was a single region (of one or more macs) at each level, we would combine all available normed input sums (U, H, and D) multiplicatively. That is, each cell in a mac would multiply its $V_U$, $V_H$, and $V_D$, values (or whichever subset of them is available), resulting in the cell's total $V$ value.  These $V$ values would then be used to compute $G$ and in the remaining steps of the CSA.

But within any given afferent bundle, e.g., the mac's aff U bundle, there would in general be multiple, say $&pi;$, active features.  For each cell in the target mac, for each of its $&pi;$ afferent U bundles (one from each of the $&pi;$ active features), for each of its $Q$ active sub-bundles (a sub-bundle is the set of efferent synapses from a source cell to a target mac), we compute the weighted input from that sub-bundle's source cell.  We represent synaptic weight as signed byte, so the weights are 0..127. Although we represent weights as in 0..127, in practice, only a small set of specific values are used. Specifically, when a weight experiences a pre-post, it is set to the max, 127, but then that weight will passively decay (according to a parametrically determined schedule) over successive frames, but in several discrete jumps, e.g., 127, to 120, to 100, to 50, then to 0.  Thus, when computing the sum of weighted inputs from a mac to a target unit, we add the weights from the $Q$ active units comprising the code active in the source mac, resulting in the raw U value, denoted $u$, from that source mac to that target cell.  But we know that the max possible input from that mac to the target cell is $Q$x x 127.  Thus, we can always normalize the input from that source mac to that cell by that max possible input, resulting in a normed U value, denoted, $U$, from that mac to the target cell.  

But there is a further nuance to this calculation.  Specifically, it is generally possible that the code active in a mac represents more than one hypothesis (i.e., more than one possible input).  Let $&lambda;$ denote the number of hypotheses strongly (i.e., at close to full strength) represented by the code active in a mac. For example, the code in mac might represent $&lambda; = 2$ previously learned (stored) inputs, A and B, and let the code of A be $&phi;(A)$ and the code of B be $&phi;(B)$. Now also suppose that on the previous instance when A occurred, it was part of a sequence and it was followed by an input, C, with code, $&phi;(C)$. And also suppose that on the previous instance when B occurred, it was part of a sequence and it was followed by an input, D, with code, $&phi;(D)$. This means that on the prior instance, when the sequence [AC] occurred all of the synapses from the $Q$ active units of $&phi;(A)$ onto the $Q$ active units of $&phi;(C)$ will have been increased to their max value of 127. 

However, in the current scenario, i.e., with $&lambda; = 2$, only $Q/2$ of the cells of $&phi;(A)$ are active.  That means that on the next frame, the summations to the cells of $&phi;(C)$ will be only half as large as they were in the original instance (when all $Q$ cells of $&phi;(A)$ were active).  But since we know that $&lambda; = 2$, we can just multiply the input sum in the afferent bundle from the source mac (where $&phi;(A)$ is active at $t$) to any cell in the target mac (where $&phi;(C)$ was active at $t$+1 in the original instance) by $&lambda; = 2$.  Then the summations, via the afferent bundle from the source mac, all of cells in that target mac will have the same value as if all $Q$ cells of $&phi;(A)$ were active at $t$.

# The new way

Rather than summing inputs across the $&pi;$ active input features of a given afferent bundle, we normalize each of those inputs individually and then just multiply all the normed values together, just as we currently do when combining inputs from different bundles.
