Here are some possible changes to the underlying theory that are worth considering

## Add a mode in which all evidence combination, even within a single bundle, is multiplicative.

In the original version, where there was a single region (of one or more macs) at each level, we would combine all available normed input sums (U, H, and D) multiplicatively. That is, each cell in a mac would multiply its $V_U$, $V_H$, and $V_D$, values (or whichever subset of them is available), resulting in the cell's total $V$ value.  These $V$ values would then be used to compute $G$ and in the remaining steps of the CSA.

But within any given afferent bundle, e.g., the mac's aff U bundle, there would in general be multiple, say $Z$, active features.  For each cell in the target mac, for each of its $Z$ afferent U bundles (one from each of the $Z$ active features), for each of its $Q$ active sub-bundles (a sub-bundle is the set of efferent synapses from a source cell to a target mac), we compute the weighted input from that sub-bundle's source cell.  We represent synaptic weight as signed byte, so the weights are 0..127. Although we represent weights as in 0..127, in practice, only a small set of specific values are used. Specifically, when a weight experiences a pre-post, it is set to the max, 127, but then that weight will passively decay (according to a parametrically determined schedule) over successive frames, but in several discrete jumps, e.g., 127, to 120, to 100, to 50, then to 0.  Thus, when computing the sum of weighted inputs from a mac to a target unit, we add the weights from the $Q$ active units comprising the code active in the source mac, resulting in the raw U value, denoted $u$, from that source mac to that target cell.  But we know that the max possible input from that mac to the target cell is $Q$x x 127.  Thus, we can always normalize the input from that source mac to that cell by that max possible input, resulting in a normed U value, denoted, $U$, from that mac to the target cell.  

But there is a further nuance to this calculation.  Specifically, it is generally possible that the code active in a mac represents more than one hypothesis (i.e., more than one possible input).  For example, the code in mac might represent two possible previously learned (stored) inputs.  Mechanistically, this means that the cell that is in the code of one of those two hypotheses is currently active in about half, i.e., $Q/2$ of the mac's CMs, and the cell that is in the code of the other of those two hypotheses is currently active in the other half of the mac's CMs.  This means that any cell receiving input from that set of $Q$ cells will have an input that is about half of what it would have been in only one hypothesis was represented by the current code.  We have an easy way to determine whether or not multiple hypotheses are being represented by an active code.  We compute that number and multiply a synapse's weighted value by it to get the total weighted value for the synapse.

# The new way

Rather than summing inputs across the active input features of a given afferent bundle, we normalize each of those inputs individually and then just multiply all the normed values together, just as we currently do when combining inputs from different bundles.
